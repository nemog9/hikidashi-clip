# Hikidashi クリップ

PC で見ているページを QR コードにして、iPhone の [Hikidashi（引き出し）](https://nemog9.github.io/hikidashi-support/) に保存する Chrome 拡張機能です。サーバーもアカウントも要りません。QR の中に、作品の内容が入っています。

> Hikidashi の作者が作った、PC 用のクリップ拡張です。
> 📱 iPhone アプリ: [Hikidashi（引き出し）を App Store で入手](https://apps.apple.com/jp/app/hikidashi-%E5%BC%95%E3%81%8D%E5%87%BA%E3%81%97/id6823911890)（この拡張は、アプリとセットで使います）

## インストール
Chrome ウェブストアでは配布していません。次の手順で、手元の Chrome に読み込みます（Edge など Chromium 系でも同様です）。

1. [Releases](https://github.com/nemog9/hikidashi-clip/releases/latest) から `hikidashi-clip-vX.Y.Z.zip` をダウンロードして、解凍する（使い続ける間、フォルダは削除しない）
2. `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」から、解凍したフォルダを選ぶ
4. 更新するときは、新しい zip で同じフォルダを上書きして、拡張機能のカードで「再読み込み」を押す

## 使い方
1. 保存したいページで、ツールバーの拡張アイコンを押す。タイトル・サムネイル・作者・本文が自動で入り、QR が出る。
2. iPhone の標準カメラで QR を読み取り、「Hikidashi で開きますか？」→「開く」→「追加」。

- QR の上の欄（タイトル・カテゴリ・クリエイター・メモ）は編集でき、QR はその場で作り直される。
- ページ上で文字を選択してからアイコンを押すと、選択した文字がメモになる（X の投稿の一部だけ残す、など）。
- YouTube（`watch` / `shorts` / `live` / `youtu.be`）は動画 URL に正規化し、チャンネル名をクリエイター、カテゴリを `YouTube` にする。
- X の投稿は、本文をメモ、投稿者をクリエイター、カテゴリを `X` にする（ログインが必要な投稿も、ページに表示されていれば取れる）。
- pixiv の作品ページ（`/artworks/<ID>`）は、カテゴリを `pixiv`、投稿者名をクリエイターにする（ページの題名「…- ○○のイラスト - pixiv」から読み取り、作品名の先頭の「#タグ」は取り除く）。ページに表示されているタグは、メモの先頭に「#オリジナル #ぬるめた」の形で並べる（ページの表示を読むだけで、内部 API は使わない）。画像は、ページが共有用に出している画像（OGP）だけを使う。ログインが必要な作品（R-18 など）は、OGP が pixiv のロゴになるが、画像なしよりよいので、そのまま使う。
- 追跡パラメータ（`utm_*`、`fbclid`、`si` など）は除去する。
- QR に入る量には限りがあるため、**画像 URL はメモより優先**し、収まらないときはメモを先頭から短くする（画面に「メモは先頭 N 文字だけ」と出る）。
- **画像の自動選択（一般のページ）:** ① SNS 共有用のメタタグ（`og:image` など）→ ② `link rel="image_src"` → ③ JSON-LD の記事・商品の画像 → ④ 動画の `poster`（表示されている大きい動画。背景用の無音・自動再生・ループの動画は除く）→ ⑤ 本文中の大きな画像（面積・位置で点数づけ）→ ⑥ CSS の背景画像として貼られた大きな要素、の順に探す。
  - サイトの初期アイコン、ロゴ、Gravatar などのアバター、絵文字、1px の追跡画像、SVG、ヘッダー・サイドバー・コメント欄・広告らしい画像は、候補から外す。JSON-LD は、投稿者や運営元（author / publisher / logo）の画像を見ない。
  - 見つかった画像は、ポップアップに候補（最大 8 枚）として並び、タップで選び直せる。
- 「画像 URL」欄は編集できる。自動で取れなかった画像は、画像の URL を貼れば QR に入る。空にすると画像なし。

## プライバシーと権限
- 権限は `activeTab` と `scripting` だけです。ツールバーのアイコンを押したタブに限って、そのときだけページを読みます。
- ページの内容は、ブラウザの中で QR に変換するだけで、**外部のサーバーには何も送りません**。常時の閲覧権限も、ありません。
- QR の表示確認のためにだけ、サムネイルの画像 URL を読み込みます。

## 開発
```
node --test test/share.test.mjs                                  # エンコード/デコードのテスト
WRITE_FIXTURE=/tmp/f.txt node --test test/share.test.mjs         # アプリ互換テスト用の固定値を作り直す
```
QR の形式（`csvshelf://add?v=1&z=<0|1>&d=<base64url>`）は、`share.js`（この拡張）と、アプリ側の取り決めです。形式を変えるときは、アプリと合わせる必要があります。同梱の QR ライブラリは `vendor/`（MIT）です。
